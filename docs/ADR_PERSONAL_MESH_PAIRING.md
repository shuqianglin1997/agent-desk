# ADR：Personal Mesh 设备配对与临时局域网端点

状态：已实现第一条端到端纵切片  
日期：2026-08-10

## 决策

设备配对使用一次性、十分钟有效的 `AD1` 邀请码。邀请设备只在用户点击“添加设备”后临时监听局域网端口；邀请被使用、用户取消或超时后立即关闭。AgentDesk 启动时不默认监听局域网端口。

配对码包含已签名的 Mesh、邀请设备证书、临时 X25519 公钥和可达端点。加入设备生成自己的 Ed25519 设备密钥和临时 X25519 密钥；双方通过 ECDH + HKDF 派生一次性密钥，配对响应使用 AES-256-GCM 加密。响应只包含成员证书链、Mesh 范围账号关联密钥、可信设备目录和 Agent 目录，不包含第三方账号密码、Cookie、Token 或原始账号 ID。

新成员证书由具有 `device.admin` 的邀请设备签发，并携带可追溯到 Mesh Root 的证书链。加入、权限修改和撤销使用有序、签名的成员事件。撤销事件保留在 `mesh.db`，即使设备卡被删除，旧库存也不能使它重新出现。

## 已验证

- 两个隔离的 AgentDesk 数据目录通过真实 HTTP 回环端点完成一次性配对；
- 邀请签名、单次使用、有效期、X25519 密钥协商和 AES-GCM 解密通过；
- 新设备没有 Root 私钥，只保存自己的设备私钥和 Mesh 账号关联密钥；
- 同一实际账号在两个设备 Slot 上归入一个 AgentIdentity 和一个 AccountBinding；
- 远端权限可按能力单独增删；
- 撤销后设备目录删除，签名 revocation revision 保留；
- 协议信封拒绝篡改、过期与重放；
- 局域网监听不会随应用启动常驻。

## 仍未由此 ADR 证明

- 两台物理电脑及不同 NAT 下的配对；
- 公网信令、STUN/TURN 和中继回退；
- WebRTC 数据通道上的长期双向消息；
- macOS/Windows 的屏幕与输入权限。

这些仍属于后续 Phase 的退出条件，不能用本 ADR 的本机双端点结果替代。
