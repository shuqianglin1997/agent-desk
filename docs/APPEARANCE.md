# 外观与 Agent 列表

设置中的“视觉皮肤”提供日系猫猫与 VHS 合成波两套外观。猫猫保持默认；皮肤与明暗模式独立保存，重启恢复。切换皮肤保留 Agent、会话选择和猫外观数据。

VHS 使用风格化像素厂商符号；当前提供 Codex、Claude、DSH 图形，未知厂商使用通用符号。这是视觉支持，不代表新增账号接入。每个 Agent 可在招牌配色胶囊中选择颜色，颜色只保存于本机。

“霓虹大楼”替代 VHS 下的猫猫庭院。同厂商招牌集中，每栋三个，第四个进入下一栋。灯牌显示图标和名字，点击选择对应 Agent。没有账号时显示空状态。

卡片支持长按约 350ms 后拖动排序；Esc 或窗口失焦取消。也可用 Alt＋左右方向键调整顺序，用鼠标滚轮横向浏览。顺序在本机保存，后台刷新保留滚动位置。

设置采用固定关闭区与单一内容滚动。两套外观支持明暗主题、中文、英文、日文与减少动态效果偏好。

macOS 的运行时 Dock 图标随皮肤切换；Finder 中的安装包图标仍保持原品牌图标。

## 维护边界

皮肤样式位于 `src/skins/` 的主题层；楼宇呈现、列表交互与应用图标分别有独立模块。新增外观只消费现有 Agent 与选择状态，不改变账号、会话、设备或运行位置模型。外观设置仅写本机设置，不写全局目录。

运行 `npm run accept:ui` 验证双皮肤、明暗/三语、即时切换、排序、调色、重启恢复和楼宇布局。VHS 应用图标可用 `node scripts/generate-vhs-icon.js` 重新生成。
