# 猫猫庭院美术资产规范

当前庭院由 Canvas 程序化绘制。本规范用于未来替换为分层 PNG / atlas 时保持业务语义、坐标和回退能力一致。

## 原则

- 逻辑画布为 480 × 236，像素边缘对齐。
- 美术只表达账号、会话关注、休息和氛围，不暗示不存在的执行能力。
- 设施文字不烘焙进图片；拖动时由程序叠加名称与提示。
- 昼夜、天气、角色和设施分层，不能为每种组合导出整张大图。
- manifest 或单个资源失败时必须回退到当前程序化场景。

## 目录建议

```text
assets/yard/
  scene/
  facilities/
  cats/
  effects/
  ui/
  manifest.json
```

文件名使用小写英文和短横线，例如 `cat-sit-base.png`。

## 场景分层

| 资产 ID | 画布 | 层级 | 用途 |
|---|---:|---:|---|
| `scene.sky` | 480×236 | 0 | day/dusk/night 天空 |
| `scene.horizon` | 480×236 | 10 | 远山、云、远树 |
| `scene.ground` | 480×236 | 20 | 草地和基础纹理 |
| `scene.path` | 480×236 | 25 | 工作亭、池塘和草坪之间的通路 |
| `scene.fence` | 480×236 | 30 | 中景栅栏 |
| `scene.foreground` | 480×236 | 90 | 少量压在角色前的草叶 |
| `scene.light-mask` | 480×236 | 95 | 黄昏/夜晚灯光 |

角色主要活动带是 y=68…130。装饰物要留出至少 20×20 的落点，并避免遮挡名牌。

## 三个交互设施

| 区域 | 当前矩形 | 资产 | 真实行为 |
|---|---|---|---|
| 工作亭 `workshop` | x 10–108, y 16–78 | 建筑、桌椅、屏幕、灯 | 确认后打开账号；已运行时聚焦状态 |
| 池塘 `attention` | x 190–290, y 87–130 | 水面、岸边、涟漪 | 聚焦当前会话详情 |
| 树下草坪 `meadow` | x 288–470, y 88–130 | 树、阴影、草垫 | 保存猫位置 |

矩形是命中层，不是构图边框。视觉中心变化时应同步修改 `interactions.js`，不能用巨大的透明命中区补救。

邮筒、排队道路、远程终端或其他会暗示会话交接/执行的设施不属于现行产品，不应加入场景或 manifest。

## 猫角色

- 建议 atlas 单元 24 × 24，脚底中心锚点 (12, 21)。
- 身体、毛色/花纹、项圈、客户端吊牌与配饰分层。
- 继续支持橘、三花、奶牛、黑、白、狸花、蓝灰、暹罗。
- 客户端颜色只用于小吊牌，不把品牌 Logo 画在角色身体上。

| 动作 | 建议帧 | 状态 |
|---|---:|---|
| `idle-sit` | 4 / 2fps | onduty、普通停留 |
| `walk` | 4–6 / 6fps | 拖放后移动 |
| `work-type` | 4–6 / 6fps | working |
| `arrive-sign` | 4 / 3fps | arriving |
| `play` | 6–8 / 5fps | play |
| `loaf` | 2–4 / 1fps | rest |
| `nap` | 4 / 2fps | nap |
| `hibernate` | 4 / 1fps | hibernate |
| `confused` | 6 / 4fps | 路径错误 |
| `lifted` | 2 / 2fps | 正在拖动 |
| `pet` | 4 / 4fps | 长按互动 |

tired/exhausted 只能是覆盖层，不能替代基础动作或让工作中的猫看起来已经停止。

## 环境与 UI

- 云、雨、雪、萤火虫和水面涟漪使用低对比小帧，不能盖住名牌。
- 提示符只保留问号、感叹号、低电量、音符和 Zzz。
- 猫名牌与气泡使用可伸缩九宫格。
- 拖放区域边框由程序生成。
- 天气不代表真实气象，不出现温度、城市或雷达信息。

## Manifest 合同

```json
{
  "version": 1,
  "logicalSize": [480, 236],
  "assets": {
    "scene.sky.day": {
      "file": "scene/sky-day.png",
      "layer": 0
    },
    "cat.idle-sit": {
      "file": "cats/cat-base.png",
      "frameSize": [24, 24],
      "frames": 4,
      "fps": 2,
      "anchor": [12, 21]
    }
  }
}
```

Manifest 只描述文件、帧、锚点、层级和可着色区域，不保存账号数据或业务状态。

## 验收

- 在 1080×660 和 1440×900 窗口中，主要角色、名牌和提示可读。
- 四只猫同时在工作亭、两只猫同时在草坪时仍能辨认。
- 昼夜和天气切换不移动三个交互设施。
- 拖起、移动、放下时脚底锚点不跳。
- 工作亭、池塘、草坪的视觉中心与命中层一致。
- 关闭动画偏好后仍有清晰静态状态。
- 任意单个资产缺失时可回退，不出现白屏或无法选择账号。
