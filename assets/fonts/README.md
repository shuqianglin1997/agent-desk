# 随应用提供的字体

按钮、数字和小标签使用 Fusion Pixel（缝合像素字体）12px 比例版：

- `fusion-pixel-12px-proportional-zh_hans.otf.woff2`：中文与英文界面
- `fusion-pixel-12px-proportional-ja.otf.woff2`：日文界面

来源是项目官方发布页 `TakWolf/fusion-pixel-font` 的 2026.11.10 版，文件未作修改。字体依 SIL Open Font License 1.1 授权，全文见 `OFL.txt`；它合并的 Ark Pixel、Cubic 11 与 Galmuri 的授权在 `LICENSES/`。长文字仍使用系统字体。
